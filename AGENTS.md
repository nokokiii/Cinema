## Git Commit Guidelines

When writing git commits in this repository, follow these rules:
- Use Conventional Commits prefixes:
  - `feat:` for new features or capabilities
  - `fix:` for bug fixes
  - `chore:` for maintenance, dependency updates, or configuration
  - `docs:` for documentation updates
  - `refactor:` for code restructuring without changing behavior
  - `test:` for adding or updating tests
  - `style:` for code style and formatting changes
- Commit messages must be strictly single-line (short subject only).
- Do NOT include any commit description or body (no multi-line messages, no bullet points, no paragraphs).
- Example: `feat: add cinema seat reservation flow`
